# 零件总清单（按机器分工）

规格依据：1 分级报价 / 2.1 建模范围 / 2.3 交付清单 / 2.4 验收 / 2.5 判重。
筛子：**只做几何由我方设计决定的物件** —— 轴承座、联轴器、同步带轮、气缸、导轨滑块、紧固件这类
厂商样本件/标准件库件一律不进清单（2.5 明文不收，且五台机器一起产最容易在这里撞车）。
每台机器一个前缀（`a_`…`e_`），族谱内部变体**必须换拓扑**，纯缩放会被判重复不计数。
