## 复验续作与接受口径

先按现有证据分流，只补缺：已接受且全部哈希/版本有效者跳过生产；技术通过视觉待审者补实际八图审查；只缺 package 者仅恢复该阶段；STEP 或图像依赖 Native 已变化则补导并失效下游；设计失败保留旧 revision 后有预算修复；未知状态先调查。不得清空数据库、覆盖旧 Native、删除失败、重新编号清预算或无依据回填 PASS。

原 100 个新件与 8 个参考件是不同来源类别，作为历史基线，不计入这次 210000 新增目标；DSH 的 delivered、counts、published 不等于最终接受。family 数、结构架构数、配置数、generated、technical_pass、visual_pending、accepted_unique_new、published、delivered 分开报告。尺寸、镜像、改名、孔数网格、无功能筋条或填充段不能充当新架构证明。候选 70000 是预算，不是一次 emit 指令；60% 接受率只是算术情景。

每件须原创正向设计，完整可编辑历史、单 Body 有效闭合正体积实体、1–20000 mm、至少 20 个真实贡献 sketch/feature 节点（不是 20 个实体操作）；STEP 往返相对体积差 <=1e-4、各轴包围盒长度相对差 <=1e-3；关键尺寸 ±0.25% 编辑后恢复；八张 2000 像素视图；FCStd、STEP、必要引用、项目信息、manifest 和版本绑定证据。以上是历史工程阈值，与采购 PDF 的 40 项/32 必选分开映射。可选二维图是原第三章加分项，不冒充每件必备。旧包实际 93 套图纸（85 新+8 参考），15 新件缺图纸。不得声称原 19 检查已覆盖全 40 项。

功能验收检查通道连通/隔离、端口角色、量规自身有效、真实材料接触、阻挡和泄漏；结合 P001 肋挡孔、TC/RC 工具空腔重叠、RF 量规断开、CA 量规落在空腔、QC/HS 参数依赖失败建立真实负例。VH、DP、CY 仍挂起排除。修改检查适用范围须披露版本、原因和保留失败负例，不能降低阈值换 PASS。八图须人真实查看并绑定产物哈希；模型可辅助，不代签人工接受。保持 manufacturing_release=false，不宣称材料、耐压、寿命、制造可用已经认证。

## 全局登记与并发边界

复用现有 intake、fleet_runner、SQLite job/delivery 和 shared/fingerprints。统一验收、接收索引和租约适配仍是待实现，不新建平行调度系统。A 的协调角色初期作为唯一全局接收写入方，A 生产也同等受审；各机只回传自己的 registry delta，不合并或覆盖别机 SQLite。新 ID 建议 f3_<machine小写>_<family>_<六位序号>，revision 单列；先全局占号，旧 ID 永久保留 alias。候选 owner 变更不改变 canonical，不重复计数。

每次领取绑定 canonical、revision、owner、lease token/到期时间、合同和源码哈希。确认并发原子性负例，同一候选只能有一个有效租约；单个 lock 文件或 git push 本身不证明原子性。未知/过期租约先核查执行和产物再恢复。全局接收方用相同基线 revision 做 Native 特征图及 BRep 去重，粗筛必须证明不漏缩放、镜像和跨族重复。离线/基线不全只能保存已授权在途，不增加最终接受数。

最终接受是同一 revision 通过技术、功能、全局去重和人工视觉后的 canonical 唯一接收事件；发布/复制 outbox 是后续事件。失败事件不可被最后一条 DONE 抹掉。视觉待审与 reserved 占容量，接受只计一次；五机本地计数不能直接相加。配额余额由同一全局账本计算，到 210000 停止新领取；验证 N−1→N 仅增一、N 后新生成零及历史 hash 不变。

## 有界修复与阶段扩产

建议设计预算含首次最多 5 次，原“最多重试五次”语义须在生产合同确认，未确认不要自行解释成无限轮。设计修订、阶段重跑、网络重连、probe 窗口分别计数，跨机器和队列不清零。达到预算仍失败置 HELD，保留全部证据。同一根因连续 3 次失败暂停相关族调查。每次推理任务简单分级：低难度自有 API、中等 DeepSeek 官方、困难 Codex；路由及 Qwen 修复闭环当前未整合。无模型权限或端点缺失则 UNKNOWN/阻断，不读取密钥或冒称调用成功。

完成阻断与恢复计划后，按授权分阶段：每机 1 件完整闭环，再累计 5 件跨至少两子族，再累计 25、100；之后单批最多 500，前两波稳定且全局接收无积压才允许单波最多 2000。已有合格证据可抵扣阶段工作，旧 2000 项 scaffold 不自动允许扩产。每个新族先单件，新引擎/核心/规则版本重新验证影响范围。初始每机一个构建任务，package 全生产根单槽；probe 并发按 p95 内存实测，不照抄 workers=3。

人工待审初始上限建议每机 25，达到后先补审；出现未知锁、丢失 FAIL、哈希异常、缺基线、资源不足、OOM 未清理或重复发布即暂停新领取。磁盘按试点单件 p95、在途和一次完整备份预留。降并发不能降图像、缩减 probe 覆盖或跳硬审。总候选预算350000若不足则报告可行性缺口，不能放宽独特性凑数。
